# Senosy Governance Skills — Public Edition

حزمة عامة من مهارات الحوكمة والأعمال وإنتاج المستندات العربية، أعدّها د. أحمد السنوسي للاستخدام التعليمي والعملي مع الوكلاء الذكيين.

## المحتوى

تضم النسخة العامة **16 مهارة**:

| المجال | المهارات |
|---|---|
| الحوكمة والاستثمار | `corporate-governance-builder`، `governance-os`، `investment-feasibility-study` |
| العقود والمقترحات | `alaqqad`، `proposal-pdf` |
| المستندات العربية | `arabic-docx`، `arabic-pdf`، `altanween-rtl-pdf`، `arabic-office-qa`، `samt-arabic-executive-layout` |
| العروض والتدريب | `build-arabic-training-decks`، `compress-arabic-executive-decks`، `generate-contextual-training-decks`، `gptimage2-pptx`، `presentation` |
| البحث الأكاديمي | `msu-thesis` |

التفاصيل موجودة في [INDEX.md](INDEX.md).

## الاستخدام

انسخ مجلد المهارة المطلوبة من `skills/` إلى مجلد المهارات في بيئة الوكيل الذي تستخدمه. اقرأ `SKILL.md` داخل كل مهارة لمعرفة شروط التشغيل والتبعيات المطلوبة.

لا تشغّل كل المهارات في المهمة نفسها. اختَر مهارة المجال أولًا، ثم أضف مهارة الإخراج المناسبة، ثم نفّذ فحص الجودة العربي عند إنتاج Word أو PDF أو PowerPoint.

## حدود النسخة العامة

- لا تحتوي على مهارات Anthropic الرسمية أو الملفات التي يمنع ترخيصها إعادة التوزيع.
- لا تحتوي على `node_modules` أو ملفات cache أو مفاتيح أو بيانات اعتماد.
- خطوط Thmanyah غير مرفقة. استخدم نسخة مرخّصة محليًا واضبط `ALTANWEEN_FONTS` عند استخدام `altanween-rtl-pdf`.
- بعض المهارات تحتاج أدوات أو مكتبات أو اشتراكات خارجية؛ راجع تعليمات كل مهارة.
- المخرجات القانونية والمالية والتنظيمية تحتاج مراجعة بشرية متخصصة قبل الاعتماد.

## الملكية والترخيص

المستودع متاح للعرض العام، لكن لم يُمنح له ترخيص مفتوح المصدر حتى الآن. حقوق المكونات الأصلية محفوظة لد. أحمد السنوسي، وتظل الأدوات والخدمات الخارجية خاضعة لتراخيص أصحابها.
