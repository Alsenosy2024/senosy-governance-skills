# بوابات الجودة — لا تسليم قبل اجتيازها

## 1. بوابة الأدلة
- كل ادعاء مادي مسند إلى `SRC-###` أو موسوم `تصميم/افتراض`.
- التعارضات مسجّلة (أو مُستبعدة بقرار المستخدم الصريح).
- لا بيانات شخصية أو سرية منشورة بلا داعٍ.

## 2. بوابة الحوكمة
- كل فئة قرار مادية موجودة في `DEC`.
- **لا سطر DOA بلا اعتماد نهائي.**
- عتبات رقمية حيثما أمكن، لا «حسب الصلاحية».
- مسار الاستثناء والطوارئ مضبوط ومحدد المدة.

## 3. بوابة الإجراءات
- كل SOP: مُشغِّل · حدود · خطوات · بوابات · **نقطة اعتماد ← سطر DOA موجود** · ضابط · دليل · SLA · استثناء · مسار رفض · تصعيد · مؤشر.
- كل بوابة لها مساران مسمّيان، ومسار «لا» حقيقي.
- **اختبار الموظف الجديد**: ينفّذه بلا شرح شفهي.

## 4. بوابة الضوابط والمؤشرات
- كل ضابط: هدف · نوع · مالك · تكرار · دليل · **طريقة اختبار**.
- **لا ضابط يتيم.**
- كل مؤشر: معادلة · مصدر · دورية · مستهدف · عتبة · **استجابة إلزامية**.
- كل مخاطرة: `سبب ← حدث ← أثر` · مالك · استجابة · ضابط · KRI.

## 5. بوابة المنتج (HTML/PDF)
- يفتح **offline**؛ صفر طلبات شبكة (`grep -c '<script src="http\|link.*http'` = 0).
- RTL سليم ومزج اللغتين صحيح (`bdi` للروابط).
- البحث والتعليقات (إضافة/تعديل/حل/حذف/تصدير/استيراد) والفلاتر تعمل.
- طباعة A4 بـ8pt · رأس وتذييل وترقيم صفحات · **لا تداخل ولا فيض ولا بتر**.
- التعليقات تُدرَج بـ`textContent` لا `innerHTML`.

## 6. بوابة التحقق الآلي
```bash
python3 verify.py          # صفر إخفاقات — إلزامي
```

## 7. بوابة المعاينة البصرية — لا تتخطّها
```bash
pdftoppm -f N -l N -r 58 -png out.pdf p    # ثم اقرأ الصورة فعلياً
```
افحص **8 صفحات على الأقل**: الغلاف · فاصل جزء · صفحة إجراء بخريطة تدفق · صفحة جدول كثيف (10 أعمدة) · صفحة سياسة · صفحة وصف وظيفي · صفحة استراتيجية · صفحة دليل.
**الـvalidator لا يرى التداخل البصري. عينك ترى.**

## 8. بوابة الحالة النهائية
اذكر منفصلاً: ما هو **مصمَّم** · ما هو **معتمد** · ما هو **مُهيَّأ** · ما هو **مُجرَّب** · ما هو **فعّال** · القرارات المفتوحة.
**لا تجمعها أبداً في ادعاء واحد بـ«اكتمال الحوكمة».**
