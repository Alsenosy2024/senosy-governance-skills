# الاستوديو المحلي للعروض الطويلة

## التشغيل

```bash
python scripts/studio.py --open --data-dir ./studio-runs
```

يفتح الخادم على `127.0.0.1:8765` افتراضياً. المجلد المحدد في `--data-dir` يحتوي
كل مهمة في مجلد مستقل: PPTX وDeckSpec JSON وتقرير QA، وPDF إذا كان LibreOffice متاحاً.

## بنية العرض الطويل

- 4 شرائح افتتاحية ثابتة الوظيفة: غلاف، سؤال، نواتج، خريطة.
- بقية الشرائح توزع على المحاور بأوزان نسبية، وبحد أدنى منطقي لكل محور.
- 4 شرائح ختامية: حالة تكاملية، تقييم بعدي، نقل أثر، التزام.
- في وضع AI يتم توليد كل محور كطلب مستقل ثم دمج الوحدات وفحص العدد.

هذا التقسيم يمنع طلباً ضخماً هشاً من 200 شريحة، ويسمح بإعادة توليد وحدة واحدة لاحقاً.

## المزودات والأسرار

الواجهة تخزن اسم متغير البيئة فقط، مثل `OPENAI_API_KEY`. ضع قيمة المفتاح في بيئة
تشغيل الخادم. مسار Codex CLI يستخدم جلسة Codex المحلية ولا يقرأ بيانات اعتمادها.

## سياسة الثيمات

- `single`: ثيم واحد للعرض كله.
- `alternating`: تبديل منضبط بين الوحدات.
- `contextual`: اختيار ثيم الوحدة من كلمات محتواها، مع الحفاظ على الخطوط والبنية والترقيم.

الثيم هنا نظام ألوان دلالي للوحدة، وليس لوناً عشوائياً لكل شريحة.
