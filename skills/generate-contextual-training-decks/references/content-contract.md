# عقد المحتوى وDeckSpec

## الغرض

`DeckSpec` هو الحد الفاصل بين الذكاء الاصطناعي ومحرّك PowerPoint. أي مزود يمكنه التخطيط، لكن المصيّر لا يقبل إلا هذا العقد. هذا يمنع ربط التصميم بنموذج بعينه، ويسمح بإعادة التصيير من دون تكلفة AI.

## بنية المستوى الأعلى

| الحقل | الغرض |
| --- | --- |
| `title`, `subtitle` | هوية العرض |
| `program_name` | اسم البرنامج في الفوتر |
| `audience`, `duration` | سياق التدريب |
| `learning_objective` | ناتج أداء قابل للملاحظة |
| `theme` | الخط والألوان والشعار والفوتر |
| `slides` | قائمة الشرائح المرتبة |

اكتب الاتجاه `rtl` واللغة `ar` للعروض العربية. لا تضمّن الخطوط داخل الحزمة؛ اذكر اسم الخط واترك بيئة التشغيل توفره.

## أنواع الشرائح

| النوع | استخدمه عندما تكون العلاقة الأساسية… |
| --- | --- |
| `cover` | تعريف العرض ووعده |
| `section` | انتقالاً بين وحدات |
| `statement` | فكرة واحدة أو سؤالاً محورياً |
| `concept` | مفهوماً مع 2-5 عناصر |
| `process` | خطوات سببية أو تشغيلية |
| `timeline` | مراحل مرتبطة بزمن أو نضج |
| `comparison` | مفاضلة بين خيارات |
| `metrics` | أرقاماً أو مؤشرات موثقة |
| `case_study` | موقفاً وقراراً ومفاضلة |
| `activity` | تطبيقاً بمخرج ومعيار |
| `quiz` | سؤالاً وخيارات وإجابة |
| `tool` | قالباً أو أداة قابلة للاستخدام |
| `summary` | استخلاصاً أو التزاماً |
| `auto` | ترك التصنيف للمصيّر عند استيراد محتوى قديم |

## الحقول المرئية

- `title`: عنوان فريد؛ استهدف أقل من 12 كلمة.
- `subtitle`: سياق أو وعد؛ لا يعيد العنوان.
- `body`: فقرة واحدة؛ استهدف أقل من 55 كلمة.
- `bullets`: حتى خمس نقاط في المعتاد.
- `items`: عناصر منظمة من `label`, `title`, `text`, `value`, `note`.
- `choices` و`answer_index`: للاختبار.
- `takeaway`: استخلاص واحد أو مخرج نشاط.
- `layout_hint`: اسم variant من كتالوج التخطيطات؛ اتركه فارغاً للاختيار الآلي.

## ملاحظات الميسّر

أكمل داخل `notes`:

`objective | timing | script | instruction | answer_or_debrief | transition`

لكل نشاط: الزمن، تكوين العمل، المخرج، ومعيار النجاح. لكل اختبار: الإجابة والتبرير. أضف المراجع في `sources`، وسيضعها المصيّر داخل كتلة `[Sources]` في Notes.

## نموذج brief للمنصة

```text
الموضوع: إدارة المخاطر في مشاريع المقاولات
الجمهور: مديرو مشاريع متوسطو الخبرة في السعودية
المدة: 3 ساعات
العدد: 28 شريحة
ناتج الأداء: يستطيع المتدرب بناء سجل مخاطر، وتحديد الاستجابة والمالك ومؤشر الإنذار
النمط: ورشة تطبيقية، أمثلة مقاولات، عربية RTL
المصادر: الملفات المرفقة فقط، وأي مصدر خارجي يجب أن يوضع في Notes
العلامة: الألوان والخط والشعار المرفق
```

صدّر JSON Schema بالأمر:

```bash
python scripts/generate_deck.py schema --out deck.schema.json
```
