# هندسة التعلّم والتيسير

استخدم هذا المرجع مع كل حقيبة تدريبية. هو إطار عمل، وليس نصاً يُنسخ إلى الشرائح.

## مبادئ تشغيلية

| المبدأ | التطبيق في الحقيبة |
| --- | --- |
| التماسك | احذف أي معلومة أو صورة لا تخدم الهدف أو القرار أو التطبيق. |
| الإشارة | ميّز العلاقة أو القرار المهم بعنوان دال أو لون تأكيدي أو سهم واحد؛ لا تلوّن كل شيء. |
| التجزئة | قسّم المهمة المعقدة إلى قرار أو خطوة واحدة قابلة للتجريب، ثم ابنِ عليها. |
| المثال المحلول ثم التطبيق | اعرض مثالاً قريباً من السياق، ثم قدّم حالة مشابهة أقل دعماً، ثم تطبيقاً مستقلاً. |
| الاستدعاء والتغذية الراجعة | اطلب من المتدرب أن يقرر أو يبرر أو يطبق؛ لا تكتفِ بسؤال «هل توجد أسئلة؟». |

## قالب وحدة من 20 إلى 40 دقيقة

1. موقف قصير أو سؤال تشخيصي يكشف الفجوة.
2. هدف تعلم ظاهر بلغة أداء.
3. مفهوم أو أداة واحدة مع مثال.
4. تطبيق فردي أو ثنائي أو جماعي، مع وقت ومخرج معلن.
5. مناقشة استخلاص: ما القرار؟ ما الدليل؟ ما الذي سيتغير في الواقع؟
6. تحقق فهم قصير وتغذية راجعة.

## اختيار النشاط

| إذا كان المتدرب يحتاج إلى… | استخدم… | مخرج قابل للتقييم |
| --- | --- | --- |
| تمييز مفهوم | فرز بطاقات أو تصويت مبرر | تصنيف مع سبب |
| اتخاذ قرار تحت غموض | سيناريو متفرع أو بطاقة تغيّر | قرار ومفاضلة موثقة |
| إتقان أداة | نموذج معبأ ثم نموذج فارغ | أداة مكتملة وفق معيار |
| مواءمة فريق | حوار أدوار أو محاكاة اجتماع | رسالة قرار أو سجل قرار |
| نقل الأثر | خطة 30 يوماً ومراجعة زميل | التزام ومؤشر متابعة |
