# التنوين — محرّك دلائل PDF العربية الاحترافية

مهارة لبناء وثائق PDF عربية (RTL) متعددة الصفحات بهوية بصرية متنوّعة وراقية. القلب هو محرّك جاهز
(`scripts/altanween_engine.py`) يوفّر: نظام ثيمات لكل فصل، مكتبة أيقونات خطية مرسومة بالكود (vector)،
ترويسة وفوتر ملوّنين، وعشرة مكوّنات عرض متنوّعة تكسر نمطية "عنوان-فقرة-عنوان-فقرة".

## فلسفة التصميم (لماذا هذه المهارة موجودة)

الدلائل العربية الطويلة تقع عادةً في فخّين: نمطية قاتلة (كل صفحة تشبه التي قبلها)، وفراغات ميتة
(محتوى قصير مع تخطيط فضفاض). هذه المهارة تعالج الفخّين عبر:

- **ثيم لون لكل فصل**: القارئ يشعر أنه دخل فصلاً جديداً بمجرد تقليب الصفحة.
- **تنويع أنماط العرض**: خط زمني رأسي، كروت أفقية، عمودان متقابلان، شرائط إحصائيات، مخططات تدفق.
- **أيقونات خطية بجانب العناوين والمفاهيم**: تكسر الرتابة وتوجّه العين.
- **توزيع طبيعي لرأي الخبير والملاحظات**: بأساليب متغيّرة (اقتباس / صندوق / ملاحظة) لا وصفة ثابتة.
- **خط كبير ومريح**: المتن 11.5pt مع تباعد 18–19 — لا تصغّره تحت 10.5 في المتن.

## متى تستخدمها

أي طلب لوثيقة PDF عربية متعددة الصفحات: دليل، كتيّب، تقرير، ملخص نقدي، محتوى تدريبي أو تسويقي.
إن كان المطلوب صفحة أو صفحتين بسيطتين فقط، فاستخدام `arabic-pdf` الأبسط قد يكفي؛ أما القيمة الحقيقية
لهذه المهارة فتظهر في الوثائق ذات الفصول المتعددة التي تحتاج هوية بصرية وتنويعاً.

## سير العمل

1. **اقرأ مرجع الـ API أولاً**: افتح `references/engine_api.md` لتعرف توقيع كل دالة بدقة قبل الكتابة.
   لا تخمّن المعاملات — المرجع يحوي التواقيع الكاملة والأمثلة.
2. **خطّط الفصول وثيماتها**: حدّد عدد الأجزاء ولون كل جزء (انظر جدول الثيمات أدناه).
3. **اكتب المحتوى منفصلاً عن العرض**: ضع نصوص كل فصل في متغيّرات/قواميس Python، ثم استدعِ مكوّنات
   المحرّك لعرضها. هذا يسهّل التعديل لاحقاً.
4. **ابنِ بتمريرتين (إلزامي للفهرس)**: الفهرس يحتاج أرقام صفحات الفواصل، وهي لا تُعرف إلا بعد البناء.
   التمريرة الأولى تبني نسخة مؤقتة وتُرجع خريطة `{رقم_الجزء: رقم_الصفحة}`، والثانية تبني النسخة
   النهائية بالأرقام الصحيحة. انظر `references/build_pattern.md`.
5. **راجع بصرياً قبل التسليم (إلزامي)**: صدّر كل الصفحات صوراً وافحصها صفحة صفحة. استخدم كاشف الفراغ
   الآلي في `scripts/whitespace_scan.py` لرصد الصفحات نصف-الفارغة، ثم وزّع المحتوى أو أضف مكوّنات.
6. **سلّم عبر `present_files`** بعد نسخ الـ PDF إلى `/mnt/user-data/outputs/`.

## نظام الثيمات (لون لكل فصل)

المحرّك يعرّف `THEMES` (قاموس برقم الجزء → لون). الافتراضي:

| الجزء | اللون الرئيسي | الاستخدام المقترح |
|------|----------------|-------------------|
| 1 | كحلي Navy #1A3557 | المقدمات، الخلاصات النقدية |
| 2 | سيان Cyan #0E9EBB | المفاهيم، البنية التقنية |
| 3 | دهبي Gold #C8912A | الأدوات، الموارد |
| 4 | كحلي + لمسة سيان | العمليات، دورات الحياة |
| 5 | سيان | النطاقات، التطبيقات |
| 6 | دهبي | المستويات، الحوكمة |
| 7 | كحلي | المنصات، المنتجات |
| 8 | دهبي | الرؤية، خرائط الطريق |
| 0 | كحلي | المقدمة/الخاتمة المحايدة |

ألوان البراند ثابتة: `NAVY #1A3557`، `GOLD #C8912A`، `CYAN #0E9EBB`. لتغيير توزيع الألوان، عدّل
قاموس `THEMES` في بداية ملفك (انظر المرجع)، لا تعدّل المحرّك نفسه.

## المكوّنات المتاحة (نظرة سريعة)

كلها تأخذ `theme` (رقم الجزء) فتلوّن نفسها تلقائياً. التواقيع الكاملة في `references/engine_api.md`.

- `header(...)` — ترويسة بشريط لوني علوي + أيقونة + كيكر (تسمية الجزء).
- `section_head(...)` — عنوان قسم بأيقونة خطية.
- `body(...)` — فقرة عربية بخط كبير (افتراضي 11.5/lh19).
- `part_divider(...)` — صفحة فاصل كاملة: خلفية ملوّنة + رقم عملاق + أيقونة باهتة + قائمة محتويات الجزء.
- `timeline(...)` — خط زمني رأسي RTL بنقاط مرقّمة (نمط بديل للكروت).
- `hcards(...)` — كروت أفقية ملوّنة بأيقونات.
- `two_col(...)` — عمودان متقابلان (مثل: تحسين مقابل تحوّل).
- `stat_band(...)` — شريط إحصائيات بأرقام ضخمة.
- `callout(...)` — صندوق نداء أفقي بأيقونة.
- `rtl_flow(...)` — مخطط تدفق أفقي، الأسهم تتجه يساراً (اتجاه القراءة العربي).
- `expert_note(...)` — رأي خبير بنمطين: `'quote'` (خط جانبي) أو `'box'` (صندوق ممتلئ). نوّع بينهما.
- `gold_note(...)` — ملاحظة ذهبية بحدود وأيقونة.
- `icon(...)` / `icon_badge(...)` — رسم أيقونة خطية مفردة (انظر قائمة الأيقونات في المرجع).
- `footer(...)` — فوتر برقم صفحة في نقطة ملوّنة بالثيم.

## مكتبة الأيقونات

22 أيقونة خطية مرسومة بالكود (لا صور خارجية، دقة لا نهائية، لونها يتبع الثيم):
`target, compass, layers, bulb, gear, shield, chart, people, doc, bot, brain, link, search, flag,
check, route, scale, building, rocket, map, quote, star`. لإضافة أيقونة جديدة، أضف فرعاً في دالة
`icon()` (انظر `references/engine_api.md` قسم "إضافة أيقونة").

## قواعد ذهبية (من دروس مستفادة فعلية)

- **خط العناوين**: استخدم `THXB` (وهو مربوط بوزن Medium) للعناوين، و`THNUM` (Black) للأرقام العملاقة
  فقط. السبب: نقطة الفاء في الوزن الأسود تبدو نقطتين عند التكبير ("المحافظ" تُقرأ "المحاقظ"). Medium يحلّها.
- **الفراغ الميت**: بعد البناء، شغّل `scripts/whitespace_scan.py`. أي صفحة فراغها السفلي > 40% تحتاج
  محتوى حقيقياً (callout، stat_band، خبير، قائمة) — لا حشواً ولا تكبيراً عشوائياً للخط.
- **النصوص منفصلة عن العرض**: ضع المحتوى في قواميس، ومرّره للمكوّنات. يسهّل المراجعة والتعديل.
- **مخططات التدفق RTL**: في `rtl_flow` تبدأ الخطوة 1 من اليمين والأسهم تتجه يساراً — هذا الاتجاه الصحيح
  للقراءة العربية. لا تعكسه.
- **المراجعة البصرية غير اختيارية**: لا تسلّم قبل أن تفحص كل صفحة بصرياً. الأخطاء الشائعة: تجاوز النص
  لحدود الكرت، تصادم bidi في الأسطر المختلطة عربي/إنجليزي، أرقام فهرس غير متزامنة.

## التحقق السريع من البيئة

المحرّك يحتاج: `reportlab`، `arabic_reshaper`، `python-bidi`، و`Pillow` (للمراجعة البصرية).
إن لزم: `pip install reportlab arabic-reshaper python-bidi Pillow --break-system-packages`.
ملفات الخطوط غير مرفقة في النسخة العامة لأسباب ترخيصية. ثبّت الخطوط المرخّصة
لديك محليًا، ثم مرّر مسار المجلد الذي يحتوي ملفات Thmanyah المطلوبة عبر متغيّر
البيئة `ALTANWEEN_FONTS` قبل تشغيل المحرّك.

## أمثلة قصيرة لبدء صفحة

```python
import sys; sys.path.insert(0, '<skill>/scripts')
from altanween_engine import *
from reportlab.pdfgen import canvas as cv

c = cv.Canvas('/tmp/out.pdf', pagesize=A4)
TH = 2  # ثيم الجزء الثاني (سيان)
y = header(c, 'من المساعد إلى الوكيل', 'Agentic AI', TH, icon_name='bot', kicker='المفهوم 1 من 8')
y = section_head(c, 'ما هو؟', y, TH, icon_name='search')
y = body(c, 'النص العربي الطويل هنا...', y, TH)
y -= callout(c, 'رقم لافت', 'الإنفاق يتضاعف سنوياً', y, TH, 'chart') + 12
y = rtl_flow(c, ML, y, CW, ['يستلم الهدف','يضع خطة','ينفّذ','يتحقق','يسلّم'], TH,
             icons=['flag','route','gear','check','star'])
y -= expert_note(c, 'رأي الخبير هنا...', y, TH, style='quote')
footer(c, 1, 'الجزء الثاني', TH); c.showPage(); c.save()
```

للتفاصيل الكاملة وكل التواقيع: اقرأ `references/engine_api.md`.
لنمط البناء بتمريرتين والفهرس التلقائي: اقرأ `references/build_pattern.md`.

## وحدة الإضافات RTL — `altanween_rtl_extras.py`

ملف مكمّل في `scripts/altanween_rtl_extras.py` يُضيف مكوّنات متخصصة لعروض الاقتراح مع ورقة رسمية (letterhead):

```python
from altanween_engine import *
from altanween_rtl_extras import *
```

| المكوّن | الوظيفة |
|--------|---------|
| `page_background(c, img)` | رسم ورقة رسمية (letterhead) كخلفية A4 كاملة لكل صفحة |
| `Doc(path, letterhead)` | غلاف حول canvas: خلفية تلقائية + قطع صفحات داخل منطقة آمنة (SAFE_TOP/SAFE_BOT) |
| `sec(d, text)` | عنوان قسم بشريط كحلي + بار ذهبي يمين |
| `subh(d, text)` | عنوان فرعي بنقطة ملوّنة |
| `body(d, text)` | فقرة عربية متدفقة مع wrapping تلقائي |
| `bul(d, text)` | نقطة قائمة بأيقونة دائرة ذهبية |
| `rtl_table(d, widths, header, rows)` | *** جدول RTL صحيح: العمود الأول المُدرَج يظهر أقصى اليمين *** |
| `logo_card_grid(d, items, out_dir)` | شريط كروت لوجوهات المنتجات (صورة + اسم عربي/إنجليزي) |
| `HDR(t, a)` | بانية خلية ترويسة جدول (خلفية كحلي، نص أبيض، بولد) |
| `_cell(t, a, bold, fill, col)` | بانية خلية جدول عادية |

### إصلاح الجداول RTL (الأهم)

المحرّك الأصلي يرسم من اليسار → العمود الأول (المسلسل) يظهر على الشمال.
`rtl_table` تعكس الأعمدة داخلياً قبل الرسم:

```python
widths = list(reversed(widths))
header = list(reversed(header))
rows   = [list(reversed(r)) for r in rows]
```

### مثال

```python
d = Doc('out.pdf', letterhead='letterhead.png')
sec(d, 'العرض المالي')
rtl_table(d,
    [700, 6326, 2000],
    [HDR('م','c'), HDR('البند والوصف'), HDR('الإجمالي (ر.س)','c')],
    [[_cell('1','c', fill=NAVY_BG), _cell('تقييم الوضع الراهن'), _cell('12,000','c')]]
)
d.save()
```

### ملاحظات المنطقة الآمنة

```python
SAFE_TOP = H - 175    # تحت لوجو الترويسة
SAFE_BOT = 120        # فوق شريط الفوتر
```
عدّلهم في `altanween_rtl_extras.py` حسب تصميم الورقة الرسمية المستخدمة.
